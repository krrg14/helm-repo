# Simple Todo List App

A small Python todo list app with both command-line and browser-accessible modes.

## Command-line usage

1. Open a terminal in the project folder.
2. Run `python todo.py`.
3. Use the menu:
   - `a` add a task
   - `l` list tasks
   - `t` toggle complete
   - `d` delete a task
   - `q` quit

## Web usage

1. Open a terminal in the project folder.
2. Run `python app.py`.
3. Open `http://localhost:8000/` in your browser.
4. Use the web form to add, toggle, and delete tasks.

Tasks are saved to `todo.json` in the same folder.
